# Changelog
All notable changes to OpenAdmin project will be documented in this file.

## [1.0.0] - 2026-07-30

# OpenAdmin v1.0.0 初始版本

> 简短概述：完成后台管理系统全栈开发，实现用户、角色、权限、菜单等核心管理功能

## ✨ 新增功能

- ✅ 登录认证模块：实现登录、登出、图形验证码、Token 刷新机制
- ✅ 用户管理：支持用户增删改查、状态管理、角色分配、部门关联
- ✅ 角色管理：实现角色 CRUD、状态控制、权限分配功能
- ✅ 权限管理：完成权限模块全量重构，支持菜单权限精细化控制
- ✅ 菜单管理：实现动态菜单系统，支持多级菜单、权限标识、状态管理
- ✅ 部门管理：新增部门树形结构管理，支持批量删除功能
- ✅ 岗位管理：实现岗位 CRUD 及部门关联查询
- ✅ 日志系统：新增操作日志和登录日志管理功能
- ✅ 在线用户：实现在线用户监控与管理功能
- ✅ 动态路由：实现基于权限的动态路由加载与菜单渲染
- ✅ 主题系统：支持多主题切换、多字体配置、灰度模式
- ✅ 布局组件：封装侧边栏、面包屑、标签页、全屏切换等核心布局
- ✅ 标签页管理：实现多标签页管理、右键菜单、滚动优化
- ✅ 代码预览：新增代码高亮预览功能与主题配置

## 📦 工程优化

- ✅ 请求封装：统一请求拦截器，实现 Token 自动刷新与错误处理
- ✅ 类型定义：完善 TypeScript 类型系统，覆盖所有业务模块
- ✅ 状态管理：基于 Pinia 实现全局状态管理（用户、菜单、标签页、主题）
- ✅ 工具函数：封装颜色处理、请求重载、版本检查等实用工具
- ✅ 数据库迁移：使用 Alembic 实现数据库版本管理与迁移
- ✅ 中间件系统：实现应用上下文、日志记录、跨域等中间件
- ✅ API 模块化：按业务模块拆分 API 接口，统一请求配置

## 🐛 Bug修复

- ✅ 修复请求过滤逻辑错误
- ✅ 调整用户菜单列表接口路由路径
- ✅ 优化在线时长计算逻辑
- ✅ 修复分页查询偏移量问题

## 🛡️ 安全更新

- ✅ 实现 JWT Token 认证机制
- ✅ 新增权限校验中间件
- ✅ 敏感接口添加权限标识控制
