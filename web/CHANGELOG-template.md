# OpenAdmin 发版 CHANGELOG 模板

> 两种模板按需复制，粘贴至 CHANGELOG.md 文件【最顶部】：
>
> - 版本规范：语义化 MAJOR.MINOR.PATCH
> - [x.y.0] → 主/次版本(功能迭代) 使用【模板A】
> - [x.y.1+] → 补丁小版本(Bug修复) 使用【模板B】

## 模板A｜大版本迭代（MAJOR / MINOR，x.y.0）

```markdown
## [x.y.0] - YYYY-MM-DD

# OpenAdmin vx.y.0 版本名称

> 简短概述：本次迭代核心改动一句话总结

## ✨ 新增功能

- ✅ 

## 📦 工程优化

- ✅ 

## 🐛 Bug修复

- ✅ 

## 🛡️ 安全更新

- ✅ 

## 📖 文档更新

- ✅ 

## ⚠️ 破坏性变更（无则整段删除）

> 升级注意事项、数据迁移指引

- 

## 🧪 待实现规划（无则整段删除）

- ⬜ 
```

```markdown
## 🐛 Bug修复

- ✅

- ✅ 
```
